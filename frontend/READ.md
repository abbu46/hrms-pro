# HRMS Pro - Human Resource Management System

A full-stack Human Resource Management System built to manage employees, attendance, leaves, and payroll efficiently.

## 🚀 Live Demo

https://hrms-pro-one.vercel.app

## 📌 Features

### Authentication
- User login with JWT authentication
- Protected routes
- Secure logout functionality

### Employee Management
- Add employees
- Edit employee details
- Delete employees
- View employee profiles
- Search employees

### Attendance Management
- Mark employee attendance
- Track present and absent employees
- Save attendance records

### Leave Management
- Apply for leave
- Approve leave requests
- Reject leave requests
- Delete leave records

### Payroll Management
- Create payroll records
- Update salaries
- Delete payroll records
- Calculate net salary
- Download salary slips as PDF

## 🛠️ Tech Stack

### Frontend
- React.js
- TypeScript
- Vite
- React Router
- CSS3

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
